# قُرّة عيني ♡

لعبة ويب عربية للتعارف الجاد، بألوان أخضر مريمي وبيج.

## التشغيل
افتحي `index.html` في المتصفح لتجربة الوضع الفردي. للعب المشترك، انشري الملفات على GitHub Pages واستخدمي رابط HTTPS.

## النشر على GitHub Pages
1. سجّلي الدخول إلى github.com وأنشئي Repository جديدًا مثل `qurrat-ayni` واجعليه **Public** للاستضافة المجانية المعتادة.
2. ارفعي الملفات الثلاثة `index.html` و`style.css` و`app.js` إلى جذر المستودع (Add file → Upload files → Commit changes).
3. من Settings → Pages، اختاري Deploy from a branch، ثم `main` و`/(root)` واضغطي Save.
4. بعد النشر، افتحي الرابط الذي يظهر في Pages، وعادةً يكون `https://USERNAME.github.io/qurrat-ayni/`.
5. اختاري «أنشئ غرفة»، انسخي الرمز المؤلف من 6 أحرف/أرقام، وأرسليه لشريكك. يفتح هو الرابط نفسه ويختار «انضم لغرفة» ويدخل الرمز. أبقيا الصفحتين مفتوحتين.

## طريقة العمل والقيود
- تستخدم النسخة الأولى PeerJS وخدمة signaling عامة لتأسيس اتصال WebRTC بين المتصفحين؛ قد لا ينجح الاتصال على بعض الشبكات أو إذا كانت الخدمة غير متاحة.
- يجب أن يكون الطرفان متصلين في الوقت نفسه؛ لا توجد حسابات أو سجل محفوظ أو استعادة للغرف.
- إجابات الأسئلة تُحفظ في ذاكرة الصفحة مؤقتًا فقط وتُنقل للطرف الآخر عبر اتصال WebRTC؛ لا يضيف التطبيق قاعدة بيانات لحفظها.
- رمز الغرفة ليس مصادقة قوية، وخدمة الإشارة الخارجية ترى بيانات الاتصال الضرورية؛ لا تشاركوا أسرارًا أو بيانات شديدة الحساسية. إذا أردتم حماية أقوى وغرفًا خاصة مستمرة، انتقلوا لاحقًا إلى خدمة خلفية مع تسجيل دخول وصلاحيات.
- GitHub Pages يستضيف ملفات الموقع فقط؛ PeerJS وGoogle Fonts يعتمدان على خدمات خارجية. الكود مفتوح المصدر إذا كان المستودع Public.
- لا تعتمدي على اللعبة وحدها للحكم على مناسبة الشريك؛ راقبي السلوك الواقعي والتوافق في الأمور الجوهرية.

## تطوير لاحق
إضافة حسابات خاصة، تخزين آمن بإذن الطرفين، سجل اتفاقات، أسئلة مفضلة، وإدارة جلسات أقوى.
