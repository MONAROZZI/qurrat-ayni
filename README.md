# قُرّة عيني ♡ — V2

لعبة ويب للتعارف الجاد، بألوان مريمية وبيج، باللغة العربية مع لمسات إنجليزية.

## المميزات
- 308 أسئلة في 14 قسمًا، بمستويات خفيفة وعميقة ومصيرية.
- خمسة أساليب للعب: صراحة وجواب، خمن جوابي، اتفقنا أو اختلفنا، ماذا لو، وBare Minimum / Princess Treatment. هذه الأساليب تستخدم نفس بنك الأسئلة مع تعليمات مختلفة؛ ليست كلها اختبارات متعددة الخيارات.
- وضع فردي وغرفة مؤقتة لشخصين عبر PeerJS / WebRTC.
- عرض إجابات الطرفين، ثم تصنيف التشابه من كل طرف، واحتفال عند الاتفاق.
- بوصلة توافق تُظهر عدد الأسئلة التي قيّمها الطرفان، ونسبة الأسئلة المصنّفة متشابهة لكل موضوع. لا تعني هذه النسب احتمالية نجاح الزواج ولا تحلل النصوص تلقائيًا.
- سؤال عشوائي وتبديل الأقسام ومستوى العمق.

## تحديث الموقع الحالي على GitHub
1. فكّي ضغط `qurrat-ayni-v2.zip`.
2. افتحي مستودع `qurrat-ayni` على GitHub، ثم `Add file → Upload files`.
3. ارفعي **كل الملفات الخمسة** إلى جذر المستودع: `index.html`, `style.css`, `app.js`, `questions-extra.js`, `README.md`.
4. أكّدي استبدال الملفات المتكررة ثم `Commit changes`.
5. من `Settings → Pages` تأكدي أن النشر من `main` و`/(root)`؛ بعد اكتمال النشر افتحي `https://monarozzi.github.io/qurrat-ayni/` وأعيدي تحميل الصفحة.

## تجربة اللعب عن بُعد
- شخص يضغط «أنشئ غرفة» ويشارك الرمز المكوّن من ست خانات.
- الآخر يضغط «انضم لغرفة» ويُدخل الرمز، وكلاهما يبقي الصفحة مفتوحة.
- صاحب الغرفة يختار القسم والمستوى ونوع اللعبة. كل طرف يحفظ إجابته ثم يكشفان الإجابات ويقيّمان تشابهها.
- بوصلة التوافق تتحدث بعد **تقييم الطرفين**؛ النتائج مؤقتة وتختفي عند تحديث الصفحة. زر «بدء بوصلة جديدة» يمسحها في الجلسة الحالية.

## الخصوصية والقيود
- الموقع نفسه منشور علنًا على GitHub Pages، لكن الإجابات لا تُنشر في مستودع GitHub ولا تُخزّن في قاعدة بيانات ضمن هذا الإصدار.
- تستخدم الغرف خدمة PeerJS عامة للإشارة لإنشاء اتصال WebRTC؛ رمز الغرفة ليس وسيلة مصادقة قوية. لا تستخدميه لتبادل أسرار شديدة الحساسية.
- يحتاج كلا الطرفين إلى الإنترنت والتواجد في نفس الوقت؛ بعض الشبكات قد تمنع اتصال WebRTC.
- لا يوجد سجل محفوظ أو تسجيل دخول، ولا ضمان استمرارية اتصال الغرفة.
- «بوصلة التوافق» وصف للاتفاقات التي صنّفها الطرفان، وليست تشخيصًا أو حكمًا على ملاءمة الشريك.
